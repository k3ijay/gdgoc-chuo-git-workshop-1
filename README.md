# GDGoC Chuo Git / GitHub Workshopへようこそ！

このリポジトリは、初心者向けにGitやGitHubの基礎を、ハンズオンを通して学べるように作られています。2026年9月26日の勉強会から使用します。

## この勉強会でやること

自分のコメントなどが書かれたのJSONファイルや、アイコンファイル（画像）を追加・編集し、プルリクエストを作成することで、以下の内容を実践しながら学びます。

* **基本的なGitのワークフローの習得**（Clone、ブランチ作成、Commit、Push）
* **GitHubを使った共同開発の流れの体験**（Pull Requestの作成、自動検証CI、マージフロー）

みんなでPRを出し合って、1つのWebページを完成させ、バージョン管理とGitHubを使った共同開発の基本を身につけましょう。

## ハンズオンの手順

当日の勉強会に参加する方はスライドと担当者の説明を、それ以外のGDGoC Chuoの方はスライドを参考にハンズオンを進めましょう。

### 1. リポジトリの準備
本リポジトリを手元にClone（またはForkしてからClone）し、作業用の新しいブランチを作成して切り替えます。

```bash
git switch -c feature/add-<your-name>
```

### 2. プロフィール（JSON）の作成
`contents/` フォルダ配下に、自分のGitHubユーザー名などをもとにしたJSONファイルを作成します。

* **配置場所**: `contents/<your-github-id>.json`
* **記述例**:
  ```json
  {
    "name": "表示名（githubのユーザー名と同じでも構いません）",
    "comment": "ひとことコメント",
    "github": "あなたのGitHubユーザーID",
    "avatar": "/images/default-avatar.png"
  }
  ```
  ※詳しくはすでに設定済みの `contents/sample.json` を参考にしてください。

### 3. （おまけ） アイコン画像の追加
独自のアイコン画像を設定したい場合は、画像を配置して `avatar` パスを指定します。

* **配置場所**: `public/images/<任意の名前>.(png|jpg|jpeg)`
* **JSONでの指定**: `"avatar": "/images/<配置した画像名>.<拡張子>"`
* **画像ルール**:
  * **正方形**（縦横比が1:1）であること
  * ファイルサイズは **2MB以下**
  * ファイル名は **半角英小文字・数字・ハイフン・アンダースコア** のみ、それ以外は使用禁止

### 4. ローカルでの動作チェック
記述ミスやルール違反がないかはローカルで確認することができます。

```bash
# 依存関係のインストール（初回のみ）
npm install

# ルール・フォーマットの検証
npm run validate
```

### 5. コミット・プッシュ & プルリクエストの作成
変更内容をコミットしてリモートにプッシュしたら、GitHub上で `main` ブランチに向けて **Pull Request** を作成しましょう。

コマンドを使う場合は以下の通りです。

```bash
git add .
git commit -m "feat: [ユーザー名]のプロフィールを追加"
git push origin feature/add-<your-name>
```

PRを作成すると、問題がなければ自動的にマージされてWebページに反映されます。

## よくあるトラブル・注意点

* **`main` ブランチでは絶対に作業しないこと**
  * `main` ブランチに直接コミットせず、必ず作業用ブランチ（`feature/...`）を切ってからPRを出してください。
* **JSONの構文エラーに注意すること**
  * カンマ（`,`）の付け忘れや、末尾の余分なカンマ、閉じカッコの漏れがないか、頻繁に確認しましょう。
* **他のファイル・共通ファイルを変更・削除しないこと**
  * 他の参加者のファイルや共通のファイルを誤って変更・削除していないか、折に触れて確かめてください。
